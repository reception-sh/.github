# Reception

Reception is a hosted support chat for mobile apps. Your customers write to you in a native chat inside your app on iOS and Android, and your team replies from the Reception dashboard, Slack or Telegram.

| Repository | For | Docs |
|---|---|---|
| [reception-ios](https://github.com/reception-sh/reception-ios) | Native iOS, SwiftUI and UIKit (Swift Package Manager) | [Native iOS guide](https://reception.sh/docs/native-ios) |
| [reception-android](https://github.com/reception-sh/reception-android) | Native Android, Jetpack Compose and Views (Maven Central) | [Android guide](https://reception.sh/docs/android) |
| [reception-react-native](https://github.com/reception-sh/reception-react-native) | React Native and Expo, iOS and Android (npm) | [React Native guide](https://reception.sh/docs/react-native) |
| [reception-flutter](https://github.com/reception-sh/reception-flutter) | Flutter, iOS and Android (pub.dev) | [Flutter guide](https://reception.sh/docs/flutter) |

[All guides](https://reception.sh/docs) · [Get started](https://reception.sh/docs/get-started) · [reception.sh](https://reception.sh)
